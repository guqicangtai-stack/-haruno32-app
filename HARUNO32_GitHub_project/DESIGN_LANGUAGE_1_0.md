# HARUNO32 Design Language 1.0

## Brand position
HARUNO32 is not farm management software. It is a performance instrument for growers who make decisions with intent.

## Core idea
**Farm Pulse — 農場の状態を、数字ではなく鼓動として感じる。**

## Signature principles
1. **One dominant signal** — each screen has one unmistakable focal point.
2. **Quiet confidence** — no decorative agriculture clichés, no leaf icons, no busy dashboards.
3. **Precision over abundance** — fewer metrics, stronger hierarchy, clear reasons.
4. **Performance ritual** — opening the app should feel like entering a cockpit.
5. **Earned status** — premium comes from disciplined utility, not luxury decoration.

## Visual vocabulary
- Obsidian: `#070908` — control, focus, precision
- Bone: `#F4F1E8` — warmth and humanity
- Signal Lime: `#C7FF33` — action and live status
- Champagne: `#D9BD77` — harvest, achievement, accumulated value
- Large numerical typography and generous negative space
- Rounded geometry with hard information hierarchy

## Copy voice
Speak as the farm, not as a chatbot.
- Good: 「今日は、伸ばせる日です。」
- Avoid: 「AIが分析した結果、良好です。」
- Good: 「守る日です。原因を一つずつ。」
- Avoid: 「注意してください。」

## Interaction rules
- Primary action: one per screen
- Alerts: reserved for decisions that change today's work
- Motion: subtle, 160–240 ms, no playful bouncing
- Sound: optional and restrained; save, complete, warning only
