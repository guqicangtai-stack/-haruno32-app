# HARUNO32 SIGNATURE / PROFIT

## Brand promise

**Less work. More profit.**  
努力量を増やすのではなく、判断の数と無駄な作業を減らし、利益につながる仕事だけを残す。

## Home screen rules

1. 最初に見せるのは情報ではなく「今日の判断」
2. DO と DON'T を同じ重さで扱う
3. 利益表示は必ず前提条件を併記する
4. 詳細データは折りたたみ、必要な人だけが開く
5. AIという言葉より、農場が何を求めているかを自然な言葉で示す

## Profit estimate

ホームの「推定粗利益」は、当日の収穫量 ×（販売単価 − 変動費）です。販売単価と変動費はホームから変更でき、端末内に保存されます。固定費、規格別単価、歩留まりなどを含まない簡易指標です。
