HARUNO32 オンライン版 v1

■ できること
・iPhone／PC対応
・5項目入力
・スマホカメラまたは写真ライブラリから複数添付
・スマホとPCの同一データ同期
・グリンへ送る文章の自動作成
・分析結果の保存
・ダッシュボード
・履歴
・JSONバックアップ
・ホーム画面へ追加できるPWA

■ 重要
このZIPだけではインターネット公開は完了しません。
オンライン化には次の2作業が必要です。

1. Supabaseで無料プロジェクトを作る
2. このフォルダをNetlify、Cloudflare Pages、GitHub Pagesなどへ公開する

■ Supabase設定
1. Supabaseで新規プロジェクトを作成
2. SQL Editorで supabase_setup.sql を実行
3. Project Settings → APIから
   ・Project URL
   ・anon public key
   を確認
4. 公開したHARUNO32サイトの「設定」に貼り付け
5. 接続確認を押す

■ 公開方法の例
Netlify Dropを使う場合:
1. このフォルダを解凍
2. Netlifyのサイト公開画面へフォルダごとドラッグ
3. 発行されたURLをiPhoneで開く
4. Safariの共有 → ホーム画面に追加

■ 現在の「グリン分析」
安全上、OpenAIの秘密鍵をブラウザへ直接入れる設計にはしていません。
そのためv1では、
  記録保存 → グリンに送る → ChatGPTで分析 → 結果を貼り付け
という流れです。

完全自動分析には、秘密鍵を守るサーバー側機能が必要です。
Sawachi自動連携も、Sawachi側のAPIまたはCSV出力仕様の確認後に追加します。

■ 写真について
Supabaseの通常アップロードは小さな写真向けです。
iPhone写真が大きくて失敗する場合は、写真サイズ縮小機能を次版で追加してください。

■ セキュリティ
supabase_setup.sql は、まず動作確認を優先した個人試作向け設定です。
URLを他人に共有しないでください。
本運用前にログイン機能とユーザー別アクセス制御を追加してください。
