# HARUNO32 Product 1.1 Design System

## Brand idea
農場の判断を、静かに強く。

## Visual principles
1. One screen, one decision
2. Dark field intelligence + warm paper
3. Lime accent only for action and life
4. Alerts use color only when action is required
5. Large type, generous spacing, plain Japanese

## Core colors
- Field Ink: #0B1510
- Warm Paper: #F3F1E9
- Growth Lime: #B7D32B
- Harvest Gold: #B8924B
- Muted Text: #68736C

## UI rules
- Main radius: 20–28px
- Buttons: text-first, 13px radius
- Cards: translucent warm white
- AI: dark card, never a separate visual gimmick
- Mobile: six-item bottom navigation
