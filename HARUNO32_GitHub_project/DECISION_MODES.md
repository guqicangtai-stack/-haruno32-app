# HARUNO32 5つの判断モード

- BOOST：条件がそろい、収量機会を取りにいく日。作業量ではなく、タイミングと精度を上げる。
- FLOW：通常管理で十分な日。うまくいっている流れを壊さず、予定外の作業を増やさない。
- RESET：根・草勢・環境のバランスを一つだけ整える日。複数条件を同時に変更しない。
- SHIELD：病害、乾燥、多湿、急変などの損失を止める日。収量より品質と被害抑制を優先する。
- WAIT：判断材料が不足、または余計な作業が不要な日。記録・観察だけを行い、資材や作業を追加しない。

各モードは、具体的な行動、判断理由、信頼度、期待効果とセットで表示する。
